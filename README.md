 Hotel Management System
A Python based hotel management system that handles room booking, check-in, check-out, and billing operations.

About
Managing hotel operations manually is inefficient and prone to errors. This system simulates core hotel management functions, allowing staff to manage room availability, guest records, and billing through a simple command-line interface.

Features

Room booking and availability tracking
Guest check-in and check-out management
Automatic billing calculation
Room status updates (available, occupied, reserved)
Simple and intuitive command-line interface


Tech Stack

Language: Python


How to Run

Clone the repository:

bash   git clone https://github.com/MelissaWachira/HOTEL-MANAGEMENT-SYSTEM.git
   cd HOTEL-MANAGEMENT-SYSTEM

Run the program:

bash   python "Hotel management sys Latest.py"

Follow the on-screen menu to manage hotel operations.
